# AstroX — Space Tourism (Responsive Web Design)

A modern, responsive landing page for a fictional space tourism company built for **Web Technologies Assignment #3**.

## Features & Implementation
- **Task 1 (Handmade Media Queries):** Custom "Featured Destinations" section built with Mobile-First CSS Flexbox and `@media` queries without Bootstrap grid classes. Supports 3 breakpoints: 375px (1 column), 768px (2 columns), and 1280px (3 columns).
- **Task 2 (Bootstrap Grid & Components):** Built using Bootstrap 5.3 CDN. Includes responsive Navbar, Hero Section with Accordion, Spacecraft Fleet cards, Mobile-only offer banner (`d-block d-md-none`), and a interactive Booking Modal.
- **Task 3 (Comparison):** Detailed evaluation of hand-written media queries vs Bootstrap grid framework.

## How to View
Open `index.html` in any modern web browser or run via Live Server in VS Code.
